# Controller typography

These fonts are bundled for offline, consistent rendering. Each font retains its
upstream name and its accompanying SIL Open Font License 1.1 notice.

| File | Upstream | SHA-256 |
| --- | --- | --- |
| `ExpletusSans-Regular.ttf` | [Google Fonts / Expletus Sans](https://github.com/google/fonts/tree/main/ofl/expletussans), unmodified `ExpletusSans[wght].ttf` (default regular weight) | `33508b3b477c548ac00179d97c6deaca1e98dab4cc1d869dec5815931e7540f8` |
| `IBMPlexMono-Regular.ttf` | [IBM Plex Mono](https://github.com/IBM/plex/tree/master/packages/plex-mono/fonts/complete/ttf), unmodified regular TTF | `7c6fbddca4b700be918f5f6183d9bd4464fa427fe435f0b480d77fe2bb8c5a43` |

The controller takes palette and typography inspiration from
[Symbolic Software](https://symbolic.software/). Expletus Sans is also used there;
IBM Plex Mono supplies an open-licensed monospace companion. No Symbolic logos,
site artwork or Berkeley Mono font files are bundled.
